# Employee Attrition Risk Analysis and Prediction System

##  Overview
This project helps organizations proactively identify employees at risk of leaving using machine learning and interactive dashboards. It combines Logistic Regression and Random Forest models to predict attrition and uses Power BI to present detailed HR insights. The system enables HR teams and decision-makers to reduce attrition-related costs by taking early preventive actions such as promotions, role changes, or training.

---

##  Methodology

The project follows these key steps:

1. **Data Loading**: Using the IBM HR Analytics dataset from Kaggle.
2. **Data Preprocessing**: Handling categorical variables, removing irrelevant columns, and scaling features.
3. **Model Training**:
   - **Logistic Regression**: A simple baseline classification model.
   - **Random Forest**: An ensemble learning model offering better accuracy and handling non-linearity.
4. **Prediction**: Generating attrition risk scores and classifying employees as "High Risk" or "Low Risk".
5. **Dashboard**: Power BI visualizations showing attrition patterns, trends, and recommended actions.

---

##  Data Source

-  **Dataset**: [IBM HR Analytics Employee Attrition & Performance – Kaggle](https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset)

The dataset includes 35+ features such as age, gender, department, job satisfaction, performance rating, salary, overtime status, and more.

## Future Enhancements

Possible future improvements to this project include:

- Balancing Data: Use SMOTE or ADASYN to address class imbalance in attrition data.
- Model Tuning: Apply GridSearchCV or RandomizedSearchCV for hyperparameter optimization.
- Add Advanced Models: Include algorithms like XGBoost, LightGBM, or Support Vector Machines.
- Real-time Prediction: Build a Flask or FastAPI backend to deploy the model as a service.
- HRMS Integration: Connect to live HR systems to refresh data automatically.
- Time-Series Forecasting: Add visualizations to monitor attrition trends over time.
- More Explainability: Use SHAP or LIME to interpret model decisions.
